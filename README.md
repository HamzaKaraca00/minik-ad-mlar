# Minik Adımlar Oyun Evi — Web Sitesi

Tek dosyalık statik site (`index.html`) + galeri görselleri (`assets/gallery/`).

## Yapı
```
.
├── index.html
└── assets/
    └── gallery/
        ├── vadi-1.jpg
        ├── vadi-2.jpg
        ├── vadi-3.jpg
        ├── vadi-4.jpg
        ├── vadi-kopru.jpg
        ├── vadi-5.jpg
        └── vadi-6.jpg
```

## Yayınlama (GitHub Pages)
1. Bu repoyu GitHub'a push edin.
2. Repo **Settings → Pages** bölümünden Branch olarak `main` (veya kullandığınız branch) ve klasör olarak `/ (root)` seçin.
3. Birkaç dakika içinde `https://<kullanici-adi>.github.io/<repo-adi>/` adresinde yayında olur.

Görsellerin yolu `assets/gallery/...` şeklinde göreli (relative) olarak bağlandığı için klasör yapısını değiştirmeden aynen push etmeniz yeterli.
